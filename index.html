JAI FORGE

    
A workshop tool for building, previewing, and publishing rich HTML bios to janitorai.com via its API — the method documented by DelightfulTempe, tooling inspired by Dezea's JAI_Publisher, built better with builder mode, lint, templates, and full local privacy.

    
Build Mode: fill the form, pick a palette, Generate — the bio writes itself. Import existing bios back into the form with one click. Everything stays editable in the code pane after.

    
Be decent: only publish to characters you own, keep layouts in-container. The method survives by not being abused.
